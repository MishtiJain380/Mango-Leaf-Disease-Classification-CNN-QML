Mango Leaf Disease Classification Using CNN and Hybrid Quantum Machine Learning
About the Project
This project focuses on identifying and classifying mango leaf diseases using deep learning and hybrid quantum machine learning techniques. It explores the application of traditional Convolutional Neural Networks (CNN) and Hybrid Quantum-Classical CNN models for image-based disease classification.
The project implements and compares two approaches: a conventional CNN model and a Hybrid Quantum-Classical CNN incorporating a simulated 4-qubit quantum circuit. The objective is to investigate their classification performance, computational efficiency, and behaviour under different training and testing data splits.
Objectives
- Develop an AI-based system for mango leaf disease classification.
- Implement a traditional CNN model as a classical baseline.
- Develop a Hybrid Quantum-Classical CNN using a simulated 4-qubit quantum circuit.
- Explore image preprocessing and feature extraction techniques.
- Compare model performance across different training and testing ratios.
- Evaluate classification performance using multiple metrics.
- Analyze execution time and computational efficiency.
- Perform data-leakage checks to ensure reliable model evaluation.

Methodology
1. Data Preprocessing
- Prepared mango leaf images for classification.
- Applied image preprocessing techniques.
- Extracted relevant features for model training.
2. Classical CNN Model
Developed a traditional Convolutional Neural Network to learn visual patterns from mango leaf images and classify different disease categories.
3. Hybrid Quantum-Classical CNN
Implemented a hybrid architecture combining classical deep learning layers with a simulated 4-qubit quantum circuit using PennyLane.
This approach explores how quantum computing techniques can be integrated into classical neural network architectures.
4. Model Comparison
Implemented and compared:
- Traditional CNN
- Hybrid Quantum-Classical CNN
Both approaches were tested using different training and testing data ratios to analyze their performance.
5. Performance Evaluation
Evaluated the models using:
- Accuracy
- Precision
- Recall
- F1-Score
- Execution Time
6. Reliability Checks
- Included a classical baseline for comparison.
- Implemented data-leakage checks.
- Compared model performance across different data splits for a more reliable evaluation.
